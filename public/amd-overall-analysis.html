決策結論

AMD 已把競爭單位從 GPU 推到 rack。Supermicro 有產品入口,沒有 anchor 位階;7/22–23 的首要任務是確認設計自由度、量產邊界與 ODM 壓價路徑。

商業意義

客戶得到的是可落地的開放 rack 選項,但只有在供應、液冷、fabric 與服務邊界可驗證時才形成購買理由。

必要行動

7/22-23 先鎖定 HPE/Dell 的整櫃主張、AMD 的 OEM 邊界與 Sanmina/ZT 路徑,會後 24 小時內更新 battlecard。

AMD Advancing AI 2026 — 整體分析報告

呈送: Supermicro 高層 製表日: 2026-07-19(活動 7/22–23,尚未舉行) 證據基礎: 官方 Cvent session catalog 121 場(12-sessions-list.md,讀取於 2026-07-19);背景取自 03-final-report.md、11-amd-vs-nvidia-compare.md 證據紀律: 場次標題／時間／房間／講者／seats 狀態 = 事實,可回查上列清單。母題歸納、市場推論、對我方影響 = 分析,凡屬推論一律標〔推測〕。全文不引用官方未公佈的規格數字。

1. 一句話結論(對 Supermicro)

這場活動的議程結構顯示:AMD 2026 的競爭主場已從「單卡」移到「整櫃 + 生態系」,而 AMD 同時在把整櫃的每一層(fabric、製造、軟體、驗證)都刻意開放成多源可替換 —— 這既給了 Supermicro 進場的縫,也同步稀釋了整合商的議價力;我方在議程上的位階(1 Breakout + 1 Alcove MtE,對比 HPE 3 場、Dell 3 場)忠實反映了「已具名 夥伴、非 」的現實,7/22–23 兩天的首要任務不是宣傳,是情報:確認留給非 anchor OEM 多少自由度。

2. 這場大會在講什麼 —— 從 121 場歸納出的 5 個母題

母題一:計價分母從 GPU 換成 token

Gartner 的「The Token Tsunami」(7/22 15:00, Breakout)、Lenovo 的「From Tokens to Outcomes」(7/23 16:00)、Spectro Cloud 的「Lose the Token Tax」(7/22 14:20)、Diamond Cooling 的「Unlock More Tokens from Today's Power」(7/22 14:40)—— 四家性質完全不同的公司,同一個詞根,散佈在 Breakout / Theater 兩種格式。 〔推測〕2026–2027 的採購對話單位是 $/token 與 tokens/watt,不是 $/GPU。凡是仍以機箱規格與 TCO 表為主軸的提案,在買方語言上已經落後一個世代。

母題二:Agentic 已改寫基礎設施需求,不只是應用層題目

「agentic」出現在 15 個以上的場次標題。更關鍵的是它的系統後果被拆成三條獨立線在講:

  • KV cache 獨立成層 —— VAST Data「Persistent KV Cache」(7/22 15:00, seats:full)、AMD「Infinity Context: Shared KV Cache」(7/23 15:00, full)、「Unified Caching (vLLM+LMCache)」(7/23 15:00)。三場獨立場次、兩場爆滿。
  • CPU 強勢回歸 —— 「Building Agentic AI with AMD EPYC CPUs」(7/23 14:00)、「Idle Capacity to Agentic AI: Scaling Inference on AMD EPYC」(7/22 15:30)、「Creating CPU Inference and Agentic Performance Transparency」(7/22 15:30, full)、Azure「From GPUs to CPUs」(7/23 14:00)、Dell「Balancing CPU and GPU for the Agentic AI Era」(7/23 15:00)。
  • 新硬體品類提案 —— Rahul Tikoo(SVP/GM Client)親講「Agent Computers」(7/23 15:00, full)。

〔推測〕agentic 的成本結構不是純 GPU FLOPs,而是「編排 CPU + 巨大記憶體 + cache 命中率」。這正是 AMD 的牌型(記憶體 +50% 是其唯一 datasheet 級硬牌,見 11-amd-vs-nvidia-compare.md),也正好是以整機/整櫃為單位競爭的系統商能施力的層級。

母題三:機櫃成為產品的最小單位,而製造層被公開商品化

在議程上被拆成兩場講:「Inside AMD Helios: Architecture」(Tech Talk, 7/23 14:00)講架構如何成立,「Deploying Rack-Scale AI Infrastructure with AMD Helios」(Breakout, 7/23 14:00,AMD Arvind Balakumar / Steve Scott + Meta Joshua Held)講怎麼裝。同一時段第三個房間是「From Silicon to Systems: Sanmina Hardware Engineering and Manufacturing Roundtable」,與談人含 Mona Hrapkowicz (ZT Systems) —— 清單中 ZT 掛 "a Sanmina Company"。 〔推測〕AMD 正在把「rack-scale 製造」制度化成一個可替代的供應層,而不是留給 OEM 談判。這對所有整合商都是議價力稀釋。注意:AMD 與 ZT/Sanmina 的合約關係不在本份 session list 的證據範圍內,此為讀名單推導,需另行查證。

母題四:電力與散熱是實質產能上限,而「驗證」是交付瓶頸

散熱獨立場次:Bull「Co-Designing Energy-Efficient Supercomputers」(7/22 14:00, Breakout)、Diamond Cooling(7/22 14:40)、Akash「Rethinking Cooling」(7/22 16:30)、GIGABYTE「Scaling Infrastructure and Advanced Cooling」(7/23 14:00)。同時出現一條被低估的線:XPerf「Validate AI Infrastructure in Hours, Not Weeks」(7/22 14:00)與 AMD「Benchmarking AI Systems」(7/22 16:00, full)。 〔推測〕整櫃的瓶頸已經不是造得出來,而是證明它是好的。驗證時間本身是出貨速度的限制因子;若驗證能從數週壓到數小時,「已驗證整櫃」這個護城河就從人力密集變成可規模化的產品。

母題五:開放化的雙面性 —— 互連與軟體都在中立化

AMD 自排「Ethernet Scale Up Networking」(7/23 13:00, David Riddoch)+ Stanford Balaji Prabhakar「Transforming Ethernet from Underdog to Champion」(7/22 16:50)+ Celestica 兩場(Open Fabrics 7/22、Scale-Up Switching 7/23)+ Arista。同時 vLLM(Simon Mo, full)、RadixArk、LMCache 三場證明 serving 層已硬體中立。 〔推測〕這是一次主動的敘事防守 —— 初期以 UALoE 隧道實作正是外界質疑效能的點(11-amd-vs-nvidia-compare.md 有 Tom's Hardware 質疑記載,標〔未證〕)。結論對我方是雙面的:互連可多源採購是好事,但互連與軟體都不再是差異化來源 —— 差異化被擠向物理層(功率、散熱、密度)與交期。

4. 市場前景 —— 2026-2027 的三個走向(全部〔推測〕)

走向一:採購指標從算力轉向「利用率 × 功率」,推論成為 rack-scale 的新理由。 DigitalOcean「Inference Performance and Economics」、Crusoe(能源優先選址)、Gartner Token Tsunami、Spectro Cloud 四場都把成本歸因到 utilization、電力與冷卻。同時 Infinity Context 若讓 KV cache 跨節點共享,推論就有了「rack-scale 才划算」的理由 —— 從訓練故事延伸成推論故事。這對做整櫃交付的一方是有利的敘事轉向。

走向二:BOM 重心上移到記憶體與 cache 層,而該層供應最不透明。 訓練場次在 121 場中明顯稀薄(僅 Primus、Zyphra、MILES RL 等少數),推論與 agentic 佔絕對多數;而 agentic 把壓力從 GPU 算力推向記憶體階層與節點間頻寬。與此同時,HBM 供應商只有 Samsung 一家露出、15 分鐘。兩件事合在一起的意思是:最關鍵的 BOM 項目,也是最沒有多源安心訊號的項目。 (自我反證:訓練內容也可能被保留在 7/23 Lisa Su 的 2 小時 keynote 裡,不下放到分場。證偽方式:聽完 keynote 回頭校正。)

走向三:主權 AI 成為獨立採購通道,但入口已被把住。 4 個獨立 sovereign 場次 + 歐洲(Bull/GENCI)+ 美國國家實驗室(LLNL)+ IBM。這批買方非 hyperscaler、預算獨立、極重視開放與可控,且不易被 hyperscaler 內製吃掉 —— 是開放架構供應商的結構性紅利。但目前歐洲入口在 Bull、美國入口在 HPE(其 3 場中有 2 場是 exascale→sovereign / enterprise 的下放敘事)。

5. 對 Supermicro 的影響 —— 機會 / 威脅 / 必須做的事

三個最大威脅(依深度排序)

  1. 製造層被制度化替代(最深層)。 Sanmina/ZT 的 45 分鐘製造 roundtable + 7 家 /EMS 同台,代表 AMD 正在確保 rack-scale 有多條製造路徑。〔推測〕2027 的整櫃毛利壓力來自這裡,不是來自對手 OEM。
  2. 從差異化滑向入場券。 GIGABYTE 直接把「Advanced Cooling」放進標題,Celestica、Bull、Akash 也都在講熱。若我方護城河只剩「我們也有液冷」會迅速失效;還沒被複製的是 100k+ 液冷 GPU/季的量產節奏(03-final-report.md §4C 引 Supermicro IR)與已驗證軟體棧的綁定,而不是「會做液冷」本身。
  3. 議程位階即關係位階。 HPE 拿到唯一掛 名的 45 分鐘 breakout;Dell 拿到 55 分鐘 MtE;我方第二場是 25 分鐘 alcove,且正面撞上兩場 Helios 主場加 Sanmina 製造 roundtable。〔推測〕這不是行政疏失。(自我反證:場次數與時長也可能受贊助層級與講者檔期影響;證偽方式:比對各廠贊助層級與展位規格。)

四個最實在的機會

  1. neocloud 是名單中最匹配我方客型的一群。 TensorWave / Crusoe / Vultr / DigitalOcean 決策快、無自建 ODM 能力、對交期與功率密度極度敏感,採購邏輯是「每機櫃可出租營收 ÷ 每機櫃總成本」。〔推測〕這條路徑可能比爭取 Helios 旗艦席位更快見營收。
  2. cache 層是 ODM 最難複製、毛利最厚的一格。 VAST Data / LMCache / Infinity Context 三場指向同一件事。〔推測〕一條「記憶體/儲存導向的推論節點」產品線(大 DRAM + 高速本機 NVMe + storage fabric),是目前尚未被任何系統廠明確命名的品類。
  3. 驗證可產品化。 XPerf 的「Hours, Not Weeks」是我方交付速度賣點的外部佐證;把第三方驗證納入出廠流程,是對抗 ODM 價格戰的交付憑證。
  4. 是真正的戰場。 「Introduction to Enterprise AI Reference Stack」(Isabelle Liu, full)、AMD Blueprints、Nutanix / Red Hat 的認證清單,決定硬體是否成為預設選項。〔推測〕被寫進參考設計的價值,可能高於任何單點效能優勢。

必須做的三件事

  • 把敘事從 TCO 表改寫成 token 經濟。 「同一電力預算下多跑多少 agent / 多產出多少 token」,比 PUE 或規格表更打中買方。
  • 企業與 hyperscaler 分開講。 Dell 的殺手鐧是服務與通路覆蓋,不是機櫃本身;在非 hyperscaler 市場,單靠速度與散熱不夠。
  • 不要在會前對 Helios 級產能做不可逆承諾。 2026 世代零(11-amd-vs-nvidia-compare.md §C),UALoE 效能仍屬〔未證〕。

3. 市場前景訊號(2026-2027)— 全部標〔推測〕

訊號 1:市場敘事的分母已從 GPU 換成 token 〔推測〕

Gartner 開場就叫「The Token Tsunami: Infrastructure Bets That Win in 2026」;Lenovo 叫「From Tokens to Outcomes」;Spectro Cloud 叫「Lose the Token Tax」。三家不同類型的公司,同一天,同一個詞根。 推論: 2026-2027 的採購對話單位是 $/token 與 tokens/watt,不是 $/GPU。誰能把整櫃報價換算成可稽核的 token 經濟,誰拿單。

訊號 2:Agentic 已經改寫基礎設施需求,而不只是應用層 〔推測〕

證據鏈:KV cache 三場獨立場次(VAST、Infinity Context、LMCache)、兩場爆滿;「Agentic AI Needs Open Infrastructure」(AMD Michael Roy,爆滿);「Building Agentic AI with AMD EPYC CPUs」;「Agent Computers」(Rahul Tikoo)。 推論: agentic workload 的特徵(長 context、多輪、多 agent 共享狀態、大量 CPU 側工具呼叫)正在把需求從「更多 FLOPs」推向「更多記憶體 + 共享快取 + 強 CPU」。這正好是 AMD 的牌型。2027 的差異化戰場在 cache 層與 CPU-GPU 平衡,不在單卡算力。

訊號 3:CPU 在 AI 敘事中強勢回歸 〔推測〕

「From GPUs to CPUs」(Azure)、「Building Agentic AI with AMD EPYC CPUs」、「Idle Capacity to Agentic AI: Scaling Inference on AMD EPYC」、「CPU Inference and Agentic Performance Transparency」、「Choosing the Right CPUs — Venice Portfolio」、Dell 的「Balancing CPU and GPU」。 推論: agentic 的 orchestration / tool-calling / 前後處理大量落在 CPU。2026-2027 的伺服器 BOM 會出現 CPU 價值回升,而 AMD 在此的位置遠強於它在 GPU 的位置。

訊號 4:Scale-up 的 Ethernet 化正在被制度化推銷 〔推測〕

AMD 自排 Ethernet scale-up breakout + Stanford 學術背書 + Celestica scale-up switching + Arista。 推論: 的實作路徑短期就是 Ethernet(與 11-amd-vs-nvidia-compare.md 記載的 UALoE 一致)。這對整合商是好事:交換層不再是專有黑盒,可多源採購;但也代表互連不再是差異化來源,大家都能買同樣的 fabric。

訊號 5:主權 AI 從概念變成獨立採購通道 〔推測〕

4 個獨立場次 + 歐洲(Bull/GENCI)+ 美國國家實驗室(LLNL/ORNL 系)+ IBM 的 sovereignty 場。 推論: 2026-2027 會出現一批「非 hyperscaler、非美國、預算獨立、極重視開放與可控」的採購方。這是開放架構供應商的結構性紅利,也是最不容易被 hyperscaler 內製吃掉的一塊。

訊號 6:Physical AI 從邊角升格為完整 track 〔推測〕

2025 年 03-final-report.md §4B 明寫「edge/IoT 非中心,edge claims 是 thin」。2026 出現:Real2Sim ×2、Physical AI kernels ×2、ROS2 三小時 workshop、Always-On Physical AI、Tool Calling Robots、AI-Enhanced Robotics breakout、Advantech edge。 推論: 這是一年之內最大的議程結構變化。2027 會有一個真實的 edge/robotics 伺服器與工作站市場浮現——但它不是資料中心 SKU。

訊號 7:製造層被公開商品化 〔推測〕

Sanmina/ZT 的 45 分鐘製造 roundtable + 7 家 /EMS 同台。 推論: AMD 正在確保 rack-scale 系統有多條製造路徑。對 OEM 是議價力稀釋,對買家是價格下降。 2027 的整櫃毛利壓力來自這裡,不是來自對手 OEM。

訊號 8:HBM 是最集中的未定風險 〔推測〕

唯一記憶體廠 Samsung,15 分鐘。 推論: 記憶體供應是 2026-2027 最大的、最不透明的 BOM 風險。名單沒有給出任何多源安心訊號。這是需要另外查證的第一優先項,不能靠這份名單下判斷。

訊號 9:Frontier lab 背書退場、量體背書進場 〔推測〕

OpenAI / xAI 從 2025 的頭條變成 2026 的缺席;取而代之是 4 家 neocloud + 一排 open-model 公司 + CVS/AT&T。 推論: AMD 的 2026 銷售引擎是「很多中型單」而非「幾張巨單」。對系統商:單數變多、單價變小、通路與交付速度的權重上升。

軟體 / 框架(vLLM/RadixArk/Red Hat/Nutanix/CIQ)機會(最高槓桿)這一整層都是可 bundle 的對象;能出「known-good ROCm + vLLM + DLC 整櫃」的人,才有毛利。
Synopsys / XPerf機會「Validate AI Infrastructure in Hours, Not Weeks」正是交付速度賣點的外部佐證,可納入交付流程做為差異化。
模型公司(Cohere/Zyphra/Chai/Featherless)機會(間接)他們證明 AMD 上能跑真工作,降低 Supermicro 賣 AMD 機的軟體風險說服成本。
主權 / 國家實驗室(LLNL/GENCI/ORNL 系)機會(結構性)主權買家重視開放、可控、非美國雲,採購週期長且不易被 hyperscaler 吃掉——但目前入口被 HPE 與 Bull 把住。

Advantech(edge)中性edge/工業賽道,與 Supermicro 資料中心主力不重疊。
Gartner中性(工具性)「Token Tsunami」是可直接借用的第三方敘事框架,拿去對 CFO 講比自報 spec 有用。
George Hotz / Linux Foundation / 學界中性生態聲量與人才訊號,無直接商業影響。
